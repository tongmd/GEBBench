# 互素跳环 — mathematics voice

$$\langle k \rangle = \mathbb{Z}_n \iff \gcd(k,n)=1$$

**定义** 在 n 个等距圆点上从 0 出发、每次前跳 k 步连弦:所得路径为一条闭合折线且遍历全部 n 点,当且仅当 gcd(k,n)=1(当 2≤k≤n−2 时即星形多边形 {n/k};k=1 或 n−1 退化为正 n 边形);否则轨道分裂为 gcd(k,n) 条互不相交的短环,每环恰含 n/gcd(k,n) 点。

**归属** 初等数论 / 群论 — 循环群 Z_n 的生成元;星形多边形 {n/k}(Poinsot 1810)

**定理** 循环群生成元定理:k 生成 Z_n 当且仅当 gcd(k,n)=1,故 Z_n 的生成元恰有 φ(n) 个(Euler 函数,Euler 1763;定理见 Gallian《Contemporary Abstract Algebra》Thm 4.2 及其推论)。星形多边形 {n/k} 的系统研究见 Poinsot (1810)。音乐实例:12 音中步长 7(纯五度)因 gcd(7,12)=1 而走遍全部十二调后回到原点——五度圈。
