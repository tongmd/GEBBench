# 鸽笼必撞 — mathematics voice

$$|A| > |B| \;\Rightarrow\; \forall f: A\to B,\ \exists\, x\neq y:\ f(x)=f(y)$$

**定义** 把多于 n 个物件放入 n 个抽屉,必有一屉含至少两件;一般地 N 件入 n 屉必有一屉含 ≥⌈N/n⌉ 件。重合的存在性纯由计数保证,但不指明发生在哪一屉。

**归属** 组合数学 — Dirichlet 抽屉原理(Schubfachprinzip,Dirichlet 1834,用于丢番图逼近)

**定理** 经典应用(Erdős 最爱的启蒙题,少年 Pósa 席间即解):从 {1,…,2n} 中任取 n+1 个整数,必有一个整除另一个。证:每个数唯一写成 2^t·m(m 为其奇部),而 {1,…,2n} 中奇数恰 n 个,即奇部只有 n 种;取 n+1 个数,鸽笼逼出两数奇部相同,其比为 2 的幂,故小者整除大者。
