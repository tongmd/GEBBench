# 图底互换 — mathematics voice

$$\exists A\;\bigl(A\in\Sigma_1^0\ \wedge\ \overline{A}\notin\Sigma_1^0\bigr)$$

**定义** 全域 X 的二划分 {F,G}：F∪G=X 且 F∩G=∅，图与底互补无缝，底本身亦自成一形。递归论给出其内在不对称：存在递归可枚举集 A（如停机集 K={e : φ_e(e)↓}），A∈Σ⁰₁ 而其补 Ā∉Σ⁰₁——「图」可机械枚举时，「底」未必可枚举。

**归属** 递归论·递归可枚举集与其补（Post 1944 互补定理）

**定理** Post 互补定理（1944）：A 递归 ⟺ A 与 Ā 皆递归可枚举。据此，停机集 K={e : φ_e(e)↓} 递归可枚举但不递归，故 K̄ 非递归可枚举——确实存在「图可枚举而底不可枚举」的集合。
