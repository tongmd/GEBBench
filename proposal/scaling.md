# Scaling motif items（这种题目怎么做多）

一个样本 = 一个抽象母题的一次"化身"。规模来自五个正交轴的笛卡尔积，
prompt 全部模板化，人只审最后一道。

## 轴 1 · 母题库 M（目标 20–40 个）

现有：自指 `s=T(s)`、递归 `T=Node(T,…)`、嵌套 `S_λ(X)=X`、环 `v⇝v`。

候选扩充（每个都有方程 + invariant + 天然场景）：

| 母题 | 方程/署名 | 自然化身举例 |
| --- | --- | --- |
| 对称/镜像 | `σ(x)=x` | 湖面倒影、蝴蝶、宫殿立面 |
| 周期/交替 | `f^n=\mathrm{id}` | 潮汐、四季、昼夜、条纹岩层 |
| 螺旋（生长×旋转） | `r=ae^{bθ}` | 鹦鹉螺、星系、蕨芽、楼梯 |
| 汇聚 | 多→一 | 支流入海、根系向干、漏斗、朝圣 |
| 发散 | 一→多 | 蒲公英、烟花、爆炸、辐射路网 |
| 星型 hub | 一点触所有 | 轮辐、机场航线、集市 |
| 链/线序 | 全序 | 商队、多米诺、河阶 |
| 格/密铺 | 平移不变 | 蜂巢、稻田、砖墙、盐田 |
| 瓶颈 | 所有路径过一点 | 山口、独桥、沙漏 |
| 渗流/蔓延 | 波前扩张 | 野火、苔藓、谣言、结晶 |
| 分层 | 偏序分级 | 地层、金字塔、军阶 |
| 缠绕/编织 | braid | 辫子、藤蔓、立交桥 |
| 对称破缺 | 规则场中一个异常 | 万绿一红、断齿轮 |
| 扭转/莫比乌斯 | 环 + 翻转 | 莫比乌斯带、衔尾蛇变体 |
| 反馈放大 | 环 + 增益 | 雪崩、啸叫、军备竞赛 |

新增一个母题 = 在 `gen_motifs.py` 的 dict 里加一个条目
（骨架渲染器 + 场景 prompt + story + math），无其他改动。

## 轴 2 · 骨架嵌入 E（每母题 5–20 个）

同一母题的多种 vis 化 + nuisance 扰动（深度、分支数、角度、布局旋转、
长宽比、随机种子）。程序生成，零成本。骨架多样性是防"模型背布局"的关键——
nuisance 在 schema 里显式记录，永不评分。

## 轴 3 · 场景域 D（30–50 个，跨母题共享）

域 = "节点/边/环在这个世界里长成什么"的映射表：

- 自然：河流、闪电、树、根系、血管、珊瑚、山脊、星轨、蛛网、沙丘
- 人造：城市、运河、铁路、梯田、庙宇、图书馆、管线、集市
- 媒介（再乘一层）：水墨、木刻、蚀刻、织物、瓷砖、摄影、长曝、航拍

**关键设计**：同一个域必须服务多个母题（航拍城市可以是环形/网格/放射/嵌套）。
域与母题正交 ⇒ 域不泄漏答案 ⇒ hard negative 免费（同域、同媒介、不同母题）。

## 轴 4 · story 域

每母题一族叙事骨架（民间故事体 / 寓言体 / 日常体）× 实体词典替换。
LLM 受限实例化后做**回译筛查**：把 story 给另一个不知情的模型判母题，
判不对就重写（这是生成侧质检，不是评测协议）。

## 轴 5 · 难度

1. 显性 → 隐性：结构占满画面 → 藏在场景一角、被部分遮挡
2. 单母题 → **复合母题**：递归×环、嵌套×自指（Droste）、对称×破缺、
   环×扭转（Möbius）——复合是 GEB 真正的深水区
3. 干扰强度：干扰项与正确项同域同媒介（只差母题）

## 生产管线

```
MOTIFS dict ──程序──> prompt = template(骨架ref, 域映射, 媒介)
            ──gpt-image (edits)──> 场景候选
            ──自动粗筛──> 骨架配准：场景 edge-map (Canny/XDoG) vs 骨架
                          chamfer/IoU —— 只查"构图跟没跟骨架"，便宜可靠
            ──人工快审 (~10s/张)──> 入库
```

- 成本：high 质量 ~$0.04–0.19/张；**1,000 张 ≈ $50–200**
- 当前骨架-ref 命中率 9/9；模板化后预计 70–90% 可用
- 组题免费：母题标签生成时已知，k-选一（给场景配故事/方程/另一场景）
  可程序化组卷，干扰项取同域异母题素材
- 发布时剥离文件名/EXIF 中的母题信息，防标签泄漏

## 示例规模

25 motifs × 8 skeletons × 5 domains × 2 media ≈ **2,000 scenes**，
story 25 × 20 = 500 篇；图像成本 ~$100–400，人工审 ~6 小时。
